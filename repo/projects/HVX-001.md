# HVX-001 — Computational Holography

**HOLOVEX Research & Innovation Lab**  
*Reconstructing Light. Redefining Vision.*

## Project objective
Build a reproducible computational-holography workflow that converts a target optical field into a phase-only hologram, numerically propagates the reconstructed field, and evaluates reconstruction quality.

## Initial research milestones
1. **Foundations:** document scalar diffraction, complex optical fields, phase-only modulation, and sampling constraints.
2. **Numerical propagation:** implement and validate Fresnel and angular-spectrum propagation against analytical test cases.
3. **Hologram synthesis:** compare Gerchberg–Saxton phase retrieval with gradient-based optimisation.
4. **Evaluation:** report reconstruction error, efficiency, speckle behaviour, and sensitivity to sampling and propagation distance.
5. **Reproducibility:** publish code, parameter files, example inputs, generated outputs, and a methods note.

## Existing implementation in this repository
The `computational_console.html` page contains interactive computational-holography demonstrations, including Gerchberg–Saxton, gradient-descent hologram optimisation, and Takeda phase recovery. The existing liquid-mixing and spray-droplet consoles are retained as supporting digital-holography research demonstrations.

## Research integrity
This is a developing research project. Numerical demonstrations should be validated against documented assumptions and reference cases before experimental or performance claims are made. Distinguish simulated results from measured results in all reports.
