1 · Digital holography: what happened

Holography records both the amplitude and the phase of light by interfering the object wave with a reference wave. A computer can then refocus the picture after recording. I did two projects with this idea at CSIR-CSIO. The first project was liquid mixing and the second was a spray of droplets.

Project 1 · Liquid mixing (first)

Water + isopropanol (IPA) in a 10 mm cuvette, 532 nm, Photron high-speed camera. I wrote a Fresnel reconstruction in Python (replacing a MATLAB workflow), tested it on a disc, then reconstructed frames at z = 45 mm, subtracted a reference and logged fringe metrics.

Project 2 · Spray droplets (second)

Off-axis Mach–Zehnder recording of a spray. Angular spectrum depth scan (50–600 mm), adaptive thresholding, focus metric, persistence filter, tracking, and statistics with bootstrap intervals: 3,246 droplets kept from 4,910 candidates; D32 = 4.52 mm for the coarse band.

3D positionD32tracking

What I learned

  • Reconstruction is only as good as the sampling: single-FFT Fresnel at 45 mm with 20 µm pixels is under-sampled.
  • My spray script is inline while the recording is off-axis, so phase was not recovered.
  • Depth scan landed on the scan edge: a measurement artefact.

2 · Computational methods: what we can do

The Computational Light Laboratory’s toolkit, Odak (github.com/kaanaksit/odak, MPL-2.0), is a PyTorch library for optics, computer graphics and visual perception. Its holography code propagates complex fields and optimises phase-only holograms with differentiable methods. Below, each method is paired with what it does and how I can use it.

3 · Use cases and the major novelty

Major novelty, stated honestly. These are contributions to discuss, not published novelty.
  1. Licence-free, end-to-end Python pipeline for hologram sequences that combines depth scanning, persistence filtering, tracking and bootstrap confidence intervals, with quality logging built in.
  2. Self-auditing results. I cross-checked code against output and reported the problems (inline vs off-axis, scan-edge depth, inconsistent number density) instead of hiding them.
  3. Sampling and Nyquist analysis for mixing holograms: a calculator showing when single-FFT Fresnel is under-sampled and when fringes exceed the camera limit.
  4. A bridge to differentiable holography: my measured recordings can serve as a physical test set for learned and optimised reconstruction.
