What happened, in plain words

  1. Built on project one. After the liquid-mixing work I applied the same idea to a spray of droplets.
  2. Recorded the spray. An off-axis Mach–Zehnder interferometer and a high-speed camera captured a sequence of holograms.
  3. Refocused every frame. The computer propagates each hologram to many depths, 50 to 600 mm, so droplets come into focus one by one.
  4. Found the droplets. Thresholding finds dark blobs, a sharpness score gives each one’s depth, and a persistence filter removes noise.
  5. Measured the spray. Sizes give D32 and size-distribution fits with confidence intervals; tracking gives speed. I also listed what is wrong, such as the scan-edge depth.

Processing pipeline

__PIPE__

Reconstruction in four equations

I = |R + O|² = |R|² + |O|² + R*O + R O*

The camera records interference. The cross terms hold the object’s amplitude and phase. The first two terms are removed by mean subtraction.

U(x,y,z) = F⁻¹ { F{U₀} · exp[ i k z √(1 − (λfₓ)² − (λf_y)²) ] }

Angular spectrum propagation to depth z. Evanescent components are set to zero and the Matsushima–Shimobaba band limit prevents aliasing. A depth stack is built from 50 to 600 mm in 5 mm steps.

z_focus = argmax S(z), S = Σ[(∂I/∂x)² + (∂I/∂y)²]

Tenengrad sharpness is evaluated inside each droplet’s bounding box.

D32 = Σ Dᵢ³ / Σ Dᵢ² = 6 ΣVᵢ / ΣAᵢ

Sauter mean diameter, recomputed live for the selection in the sidebar.

Known limits

  • The loaded data has a single depth, z = 50 mm, for every droplet. This is a scan-edge artefact, not a physical result.
  • The processing script is inline (Gabor) while the recording geometry is off-axis, so only amplitude is recovered.
  • Sphericity above 1 is not physical; it signals segmentation bias.
