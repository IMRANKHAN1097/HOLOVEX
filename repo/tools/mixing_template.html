What happened, in plain words

  1. Learned the method. Holography stores the light’s phase as fringes, so a computer can refocus the picture later.
  2. Rebuilt the lab code in Python. I replaced a MATLAB workflow with a Fresnel reconstruction I wrote myself, and tested it on a disc.
  3. Recorded the mixing. Three drops of IPA were injected into a water cuvette inside an interferometer and filmed with a high-speed camera.
  4. Reconstructed the frames. Each frame is turned into a picture at z = 45 mm. I subtract a reference frame so only the mixing disturbance remains.
  5. Measured it. For each frame the script reports fringe visibility, RMS fluctuation and SNR, and saves frames, a video and a CSV.

Camera workflow (Photron PFV)

1 · Connect. Configuration → Connection: choose the camera network settings.

2 · Set conditions. Frame rate, shutter speed, resolution (1024 × 1024), trigger mode. This panel is from the Photron manual; check what I used.

3 · Record. Press Ready, then trigger: the camera shows “Now recording”.

4 · Save. Export the frames as an image sequence, then run the Python script. The script lists five libraries: numpy (FFT), matplotlib (figures), scikit-image (image I/O), scipy (Gaussian filter) and tkinter (file picker).

Why diffusion alone cannot explain the plumes. With D = 0.9×10⁻⁹ m²/s the diffusion length after 7 s is about 0.11 mm, but the plumes are millimetres wide. Also, IPA is lighter than water, so IPA-rich fluid tends to stay on top. Downward plumes need drop momentum, surface-tension-driven (Marangoni) flow or convective instability. The model’s “effective” diffusivity and drop-penetration sliders stand in for these; they are knobs, not measurements.
